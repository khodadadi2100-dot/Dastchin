# Dastchin

فروشگاه اینترنتی دستچین — بازسازی از صفر با تمرکز بر تجربه خرید فارسی و RTL.

## وضعیت

نسخه اول شامل اسکلت رابط کاربری صفحه اصلی، دسته‌بندی، جستجو، کارت محصول، سبد خرید اولیه و منوی موبایل است.

## نقشه توسعه

1. تکمیل UI تمام صفحات مشتری
2. سبد خرید و ثبت سفارش
3. حساب کاربری و احراز هویت
4. دیتابیس محصولات، موجودی و سفارش‌ها
5. کد تخفیف و تخفیف محصولات
6. پرداخت آنلاین
7. ارسال و پیگیری سفارش با پیک
8. نظرات و امتیازدهی
9. پنل مدیریت
10. تست، بهینه‌سازی و انتشار
